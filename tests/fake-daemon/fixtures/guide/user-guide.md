# Fixture guide

This is not Band's user guide. Band's guide is read at run time from the Band install on the computer the app runs on,
and it is never copied into this project. This stands in for it while the app runs on the fake daemon, so the
Documentation screen has something to draw and something to search.

## Start here

Everything on this page is invented.

### Open a room

Pick a room from the list on the left. Its conversation opens beside it.

### Assign work

Describe the work in the composer and mention the agent that should do it.

## Rooms

A room is where a person and their agents talk.

### Read the plan

The plan card at the top of a room's conversation shows what the agent means to do.

### Share a file

Drop a file into the conversation to share it with everyone in the room.

To see who else could receive it, see [Sonar](#sonar). Band's other documents, such as
[the advanced reference](advanced-reference.md), are not part of this guide, and neither is
[a page this guide does not have](#no-such-page).

## Sonar

Sonar shows the people on this network and the agents they advertise.

### Copy a handle

Open a person, find the agent you want to reach, and copy its handle.
