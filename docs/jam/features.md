# Everything the official Jam app does

**Jam Desktop is Band Desktop since 0.4.14** (installed here 2026-10-08): the same app under BAND's new name, with a Teams section and an eighth experiment. The rows keep the words of the version they were recorded from, and Teams has its own section below.

The checklist every screen session works from, so nothing is missed. Built on 2026-09-18 from three sources, and checked against a fourth on 2026-09-19:

- **The user guide** that ships with Jam 0.4.10 (read at runtime from the Jam install; never copied here).
- **The `jam` CLI 0.4.10**: its help for all 207 commands and subcommands, read from the CLI on this computer and never copied here.
- **The daemon's routes** (`docs/jam/routes.md` lists the ones this app calls).

- **Jam Desktop 0.4.10 itself**, clicked through read-only on 2026-09-19: every section, a room's views, menus and filters, every Settings page, both themes and a narrow window. Rows marked (Jam Desktop) come from it; the captures stay on the machine that made them, as they show a real account. Where the app and its guide differ, the app wins. What still needs an agent, several rooms, a write or an experiment is under "Still to record"; where this app differs from Jam on purpose is `docs/jam/differences.md`.

How to read a row: the feature in Jam's words; the daemon routes that most likely serve it (**bold** = request and answer recorded from the live daemon, plain = known by name only, a LEAD); the session that builds it. A session ticks its rows as it ships them, and adds any row it finds missing.

Flags: **VERIFIED** = seen on this machine today · **LEAD** = inferred from a name or the guide, check before relying on it.
